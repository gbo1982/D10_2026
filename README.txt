D10 ADM customer map

Files: index.html, styles.css, app.js, data.js, map-data.json, all-adm-addresses.csv and .nojekyll. No build step required.

GITHUB PAGES
Extract this ZIP. Upload all files to the root of your repository, keeping index.html at the root alongside styles.css, app.js and data.js. In Settings > Pages, choose Deploy from a branch, main, / (root). Open the resulting GitHub Pages HTTPS URL, not the repository file preview.

ADM 144, 217, 318, 533 and 721 have independent toggles and stable colors. Multiple ADMs can display together; all are selected by default. Shared-location markers show the colors of each selected ADM at that point and list the customers in their popup. Search and CSV export respect the selected ADMs and location filters.

Mobile requests location access and follows with a 4 km radius. Pause/Resume controls map centering; dragging the map or opening a customer pauses following. GPS requires HTTPS or localhost. Location updates remain in the browser. Leaflet and map tiles require internet access.

Source: D10 app 2026 ADM.xlsx. Only nonempty customer rows imported. Provided addresses used. 762 entries located, including 106 approximate matches marked for review. Verify approximate locations before travel.
